## 🟣 Sobre o Projeto

Este projeto analisa **mais de 60.000 linhas de diálogos** e **10 temporadas** da série *Friends* para responder a questões clássicas dos fãs utilizando ciência e análise de dados com Python e SQL.

---

## 🟡 Principais Insights Encontrados

| Pergunta de Análise | Métrica / Resultado | Vencedor(a) |
| :--- | :---: | :---: |
| 🗣️ **Quem tem mais linhas de diálogo?** | Total de Falas | **Rachel Green** |
| 👥 **Qual a dupla com mais cenas juntas?** | Cenas Compartilhadas | **Chandler & Monica** |
| 🦖 **Quem estrela os episódios mais bem avaliados?** | Maior Nota Média no IMDb | **Ross Geller** |
| 🏆 **Qual a temporada mais bem avaliada?** | Média Geral IMDb | **Temporada 10** |
| 🌟 **Qual o episódio com maior nota?** | Nota 9.7 no IMDb | **T10E18 ("The Last One: Part 2")** |

---

## 🛠️ Tecnologias Utilizadas

* **Python 3**: Limpeza, manipulação de dados e lógica de agregação.
* **Pandas**: Agrupamento e combinações de dados (`itertools`).
* **PandasQL**: Consultas SQL avançadas (`SELF JOIN`, `GROUP BY`, `AVG`).
* **Seaborn & Matplotlib**: Visualização de dados.
